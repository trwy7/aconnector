Authenticating with OpenID for beginners

This is a pretty simplified explination

Automatic

A lot of OIDC clients allow automatically configuring themselves from the discovery endpoint. The discovery endpoint is at GET /.well-known/openid-configuration. Most OpenID Connect libraries should automatically configure themselves using either the discovery endpoint URL, or the issuer URL.

Here is a list of available endpoints, keep in mind not all of these may be required by your client:

  • Issuer URL: https://{{host}}
  • Authorization URL: https://{{host}}/apps/auth
  • Token URL: https://{{host}}/apps/token
  • Userinfo URL: https://{{host}}/apps/userinfo
  • JWKS URL: https://{{host}}/apps/jwks

Manual

1. Create an app

If you are seeing this, chances are, you already have! Now that you have an application, you should set the redirect url to the callback url for your application. This will be redirected to when a user accepts/denies the authorization. You should also set the launch url to the dashboard/home page of your site.

2. Redirect users

On your login page there should be a button that redirects users to the auth endpoint. The redirect should include your client id, redirect url, response type (always code for now), and scopes. Scopes are broken right now, but you should still only request what is needed.
An example redirect url would be https://{{host}}/apps/auth?client_id=your_client_id&redirect_uri=https%3A%2F%2Fexample.com%2Flogin%2Fcallback&response_type=code&scope=openid+profile+email.
